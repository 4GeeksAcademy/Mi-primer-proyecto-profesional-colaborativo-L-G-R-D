# Alcance y contenido de Maison RDL

Alcance: todas las tareas del proyecto.

- Consultar CONTEXT.md y memory-bank/requisitos.md antes de decidir estructura o contenido.
- Solo HTML y Tailwind CSS, con CSS adicional si procede; no añadir lógica JavaScript, frameworks, backend o pagos reales.
- Mantener cinco HTML enlazados; los paneles de demo no sustituyen las vistas exigidas.
- Marca ficticia con sede en Francia. No inventar año de fundación, domicilio concreto, certificaciones, reseñas, promociones o condiciones de envío.
- Datos de producto e importes proceden del inventario común que se prepare en T03; no crear catálogos incompatibles por página.
- Identificar límites estáticos donde afecten al uso y en README; no prometer búsqueda, filtrado o carrito persistente.
- No transmitir datos de checkout; mantener pago deshabilitado.
- Preservar contenido indexable, semántica y Schema.org coherentes con lo visible.
- Distinguir requisitos del campus, decisiones del equipo y propuestas. Los pendientes se registran, no se presentan como hechos.
